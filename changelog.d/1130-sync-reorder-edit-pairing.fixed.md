- **`clm slides sync`: reordering cells on one half while editing shared cells no longer livelocks or silently undoes the reorder** (#1130). When one half reordered a slide's cells and the other half (or the same half) edited un-id'd shared cells such as code, sync could pair an edited cell with the wrong slot. It then either withheld the same rows on every pass, or reported success with the reorder undone on both halves. Sync now pairs such cells using where each half's cell sat when last recorded, and moves un-id'd cells together with a reorder of the id'd cells around them in a single pass. The sync ledger gains optional per-cell position fields; the first `sync record` or `apply` after upgrading adds them to existing ledgers, so expect a one-time ledger diff.
