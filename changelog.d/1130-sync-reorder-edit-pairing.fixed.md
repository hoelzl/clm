- **`clm slides sync`: moving shared cells (code, un-id'd markdown) relative to voiceovers while editing them now converges instead of livelocking or silently undoing the move** (#1130). When one half reordered a slide's cells and either half edited the un-id'd shared cells, sync could pair an edited cell with the wrong slot. It then either withheld the same rows on every pass, or reported success with the move undone. Sync now locates such cells by where each half's copy sat when last recorded. It moves un-id'd cells together with the reorder of the id'd cells around them. A placement answer now places the cell next to the right neighbour, and brings a one-sided edit along. The sync ledger gains optional per-cell position fields: the first `sync record` or `apply` after upgrading adds them, so expect a one-time ledger diff.
