- Changed: the pre-push hook now runs a deterministic tier of the fast suite (~3-4 min instead of ~8.5 min): a new `load_sensitive` marker tags the heavyweight-process and wall-clock-timing test families (directory-driven via `LOAD_SENSITIVE_TEST_DIRS` in `tests/conftest.py` — `infrastructure/workers`, `infrastructure/backends`, `infrastructure/database`, `workers`), and `scripts/run_pytest_hook.py` excludes them with `-m "... and not load_sensitive"`. CI and a plain `uv run pytest` still run these families on every change, so no coverage moves from "automatic" to "never"; `python scripts/run_pytest_hook.py --full` runs the unfiltered suite locally. The gate's flake exposure (rotating load failures rejecting healthy pushes, xdist worker crashes killing the run) drops with the excluded families. (#926)
