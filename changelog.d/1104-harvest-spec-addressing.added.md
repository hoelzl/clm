- `clm harvest report --spec SPEC --lang L` reports every recorded deck of a course in one envelope (`"verb": "batch-report"`). Decks resolve through the spec and their videos through the recordings tree (`final/<course>/<section>/<NN title>[ (part N)].mp4`), with multi-part videos in part order. Each deck gets a status (`actionable`, `nothing`, `harvested`, `recorded`, `no_recording` or `error`) and, when actionable, the follow-up `task` command. One failing deck no longer stops the run. `--section`, `--topic` and `--deck` narrow the batch. `--resolve-only` shows the deck-to-video mapping without transcribing. `--unharvested` skips decks whose current videos are already recorded as `harvest:<fingerprint>` in the sync ledger. Videos in the tree that match no deck are listed. `task`, `accept` and `verify` accept `--spec SPEC --topic T [--deck STEM]` instead of a deck path. `--topic` is an exact topic id, so agents no longer glob deck paths: a glob once matched `topic_180_c_strings` instead of `topic_190_strings` (#1104).
